# Task 057 — Merge framework flags runtime JARs into ONE deterministic jar

## Background (user decision, 2026-08-25)

User approved **Option M**: consolidate the framework exportable-aconfig
hidden-twin-family runtime JARs into a single deterministic jar. Tasks 054/055
produced byte-identical individual jars — they are the merge INPUTS, the work is not
wasted. Goal: 1 file in libs/, 1 wiring line, provenance preserved.

## Scope

Merge family = the 14 framework exportable-aconfig runtime jars currently wired in
`SystemUI-core/build.gradle.kts`:

- 3 from tasks 053/054: `libs/window-flags.jar`, `libs/device-state-feature-flags.jar`,
  `libs/android-os-flags.jar`
- 11 from task 055: the 11 `libs/*-flags.jar` added by commit 83c347fc
  (see `git show 83c347fc --name-only` or `docs/issues/2026-08-25-aconfig-flags-batch-closure.md`)

DO NOT touch the other flags jars (systemui-flags, systemui-shared-flags, wifi-flags,
wm-shell-flags, launcher3-flags, notification-flags, settingslib-*-flags,
device-state-flags) — they are NOT the framework hidden-twin family (different
packages/owners, device-provided or app-local). They stay as-is.

## Steps

1. **Extend `tools/package_aconfig_jars.py`**:
   - Tag the 14 framework-family CONFIG entries (e.g. `family="framework"` field or a
     `FRAMEWORK_FAMILY` set — pick one clean mechanism).
   - New subcommand/mode producing `libs/systemui-aconfig-flags.jar` = deterministic
     union merge of the 14 SOURCE javac jars (merge from AOSP sources directly, not
     from the libs/ copies — though those are byte-identical, merging from sources
     keeps provenance explicit):
     - entries sorted lexicographically; fixed timestamp; fixed compression level;
       no directory entries needed unless sources have them (match zip norms); the
       merge must be reproducible (two runs → identical sha256).
     - class-set = exact union of the 14 sources' class sets; assert no overlapping
       pathnames across sources (fail loudly if collision); assert each merged entry
       is byte-identical to its source entry.
     - keep the existing per-jar five-class validator per source before merging.
   - `.uau` metadata files in sources: carry them through too (same deterministic
     rules), they are part of the aconfig runtime contract.
2. **Update `tools/tests/test_package_aconfig_jars.py`**: merged-jar determinism
   (build twice, same hash), class-set = union, per-entry byte-identity vs sources,
   collision detection, `.uau` pass-through. `uv run pytest tools/tests/ -q` all pass.
3. **Rewrite wiring** in `SystemUI-core/build.gradle.kts`: delete the 14 individual
   `implementation(files(.../libs/*-flags.jar))` lines of this family, add ONE:
   `implementation(files("${rootProject.projectDir}/libs/systemui-aconfig-flags.jar"))`
   with a grouped comment (same Chinese style) explaining: framework exportable
   aconfig hidden-twin family, deterministic merge of N byte-identical Soong javac
   outputs, generated by `uv run python tools/package_aconfig_jars.py <merge-mode>`.
4. **Delete the 14 individual jars** this family (`git rm`), keep everything else.
5. **Regenerate + verify**: run the merge; confirm `libs/systemui-aconfig-flags.jar`
   exists, classes count == sum of 14 sources' classes (expect ~14×5 plus .uau
   entries), every `Flags` class byte-identical to its old individual jar
   (`sha256sum` per-entry comparison, script it and paste evidence).
6. **Rebuild** `./gradlew :app:assembleDebug`; dex-sweep: every one of the 14
   `L.../Flags;` classes defined exactly once across all dexes; zero hidden twins.
7. **Redeploy emulator-5554** (established procedure, /data staging workaround from
   task054 report §8; stock backup path unchanged); verify `sys.boot_completed=1`,
   PID stable ≥5 min (30s samples), zero NoClassDefFoundError, zero FATAL,
   status bar present (dumpsys/screenshot evidence).
8. **Docs + commits**:
   - Report: `docs/issues/2026-08-25-aconfig-flags-single-jar-merge.md` (decision
     record M, evidence for every acceptance item).
   - Sync CURRENT_STATE.md dependency list (14 jars → 1 merged jar), STATE/log.
   - Commits (English, local only): one commit `refactor(aconfig): merge 14 framework
     flags runtime JARs into single systemui-aconfig-flags.jar (task 057)` covering
     tool+tests+jar+wiring; docs/commit may be same or separate — your call, keep
     them meaningful.
   - Also handle the untracked `pdvc_impl.txt` (task053 scratch): delete it if
     it's scratch (verify content first), or fold into the forensics doc — state
     what you did.

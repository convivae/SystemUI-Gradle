# Task 071 — C2: libs/ 全删 + AOSP-17 打包脚本适配 + 脚本再生

## 背景

- AOSP 树 `android-17.0.0_r1` 已全量构建（C1）；C3 源码重对齐完成（task070，对齐门全 0）。
- 本任务执行 ADR 0007 Phase C 验收命题：**git clone 后仅凭 AOSP 树 + tools/ Python 脚本
  可从零复现，无一手工产物**。执行顺序：先改脚本 + pytest 全绿 → sha256 快照 →
  `git rm -r libs/` → 按依赖序脚本再生 → 漂移报告。
- 版本坐标纪律：`install_aar_to_maven.py` 全族 1.x → **2.0.0**（major = AOSP vintage 16→17），
  旧 1.x 目录随全删消失。`libs.versions.toml` catalog 更新归 C4。

## chief 预勘察四项（已逐一实测复核）

1. **iconloader 结构重构**（已复核）：
   - `iconloader/javac` = 3 类（IconFactory、SimpleIconCache 门面）
   - `iconloader_base/javac` = 21 类、`iconloader_base/kotlin` = 120 类
   - 三 jar 两两不相交，闭包 144 类，全部 `com/android/launcher3/`
   - `iconloader/android_common/kotlin/` 在 17 **不存在**（旧冻结路径，已验）
   - res/manifest 源树路径不变；R.txt 改取 `iconloader_base/android_common/R.txt`
2. **WindowManager-Shell-proto 上游删除**（已复核）：
   - Soong 只剩 `WindowManager-Shell-lite-proto`（69 类：
     `desktopmode/data/persistence` 46 + `desktopmode/education/data` 13 + `apptoweb/data` 10）
   - proto/protolog 类并入主 jar：`com/android/wm/shell/ProtoLogController.class`、
     `com/android/internal/protolog/ProtoLogImpl_2006817261(. $Cache)` 在主 jar 实测存在
   - 脚本删除 nano-proto 条目，主 AAR 吸收
3. **WifiTrackerLib manifest 移位**（已复核）：源树 manifest 已删，改用 soong
   `WifiTrackerLib/android_common/GeneratedManifest.xml`
   （package="com.android.wifitrackerlib.nores"，验存）；res/R.txt 路径不变
4. **motiontoollib 上游删除**（已复核）：`frameworks/libs/systemui/` 无 motiontoollib 目录；
   全 AOSP 无 MotionToolManager；`libs/motion_tool_lib.jar` 不再产出；
   `package_viewcapture_motiontool_jars.py` 只产 view_capture.jar

## 实测新增适配项（预勘察之外，实测 17 树浮出）

5. **view_capture_proto 目标删除**（对应预勘察 "viewcapture 2/4 存活"）：
   17 的 viewcapturelib Soong 只有 `view_capture` 一个 target（bp 无 view_capture_proto）；
   VIEW_INPUTS 缩为 javac(9) + kotlin(13) = 22 类（16 时代为 9+23+24=56 类，proto 类
   随 target 删除而消失，PerfettoViewCapture 直接写 perfetto track，不再有中间 proto）。
6. **SettingsLib DeviceStateRotationLock Kotlin 产物消失**：17 该 target 已 Kotlin→Java
   重写（`PosturesHelper.java` 等），javac jar（13 类）由 discovery 自动发现；
   显式 device-kotlin 输入必须从 code 列表删除（否则 FileNotFoundError）。
7. **SettingsLib 闭包漂移**：34 个 discovery javac jar（884 类，两两不相交）+
   主 Kotlin（488 类）= **1372 类**（16 时代 1153）；Theme Kotlin **29 类**（16 时代 15），
   全部 `com/android/settingslib/widget/`，与主闭包零重叠（实测）。
8. **Traceur 漂移**：TraceurCommon 14 类 + perfetto protos 753 类 = **767 类**（16 时代 640）；
   Traceur res 105 文件不变；FileSender/PresetTraceConfigs/TraceConfig R8 目标存活。
9. **WM-Shell 主产物漂移**：主 javac 1423 + 主 kotlin 1632 + lite-proto 69 = **3124 类**
   （16 时代 1888）；16 时代 exclude 的 3 个 shared AIDL 类在 17 主 jar 已不存在
   （exclude 前缀保留为防御性 no-op）；nano 包（`com/android/wm/shell/nano/`）全消失；
   persistence proto 迁入 lite-proto 命名空间 `desktopmode/data/persistence/`。
10. **SettingsLib per-target res 数漂移**（Batch 4D 十族，实测）：
    MainSwitch 24、AppPreference 91、BannerMessage 112、BarChart 6、Button 29、
    Footer 92、Illustration 9、Slider 4、Usage 2、SettingsSpinner 20，合计 **389**
    （16 时代 346）。

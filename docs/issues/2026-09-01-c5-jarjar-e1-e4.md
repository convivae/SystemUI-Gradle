## 背景

Task 078 已把 AOSP 17 platform aconfig JarJar 错位固化为秒级静态 gate，并从 Soong 主源确认：权威 `repackaging.txt` 有 725 条 exact rules（726 物理行），stock SystemUI 的 R8 program input 按产物混用普通和 `repackaged-jarjar` 变体，而 Gradle Release 当前仍保留四个 runtime-critical 原名引用。当前 gate 为：

- Gradle Release：exit 1，30 source（3 definitions）/ 0 target（0 definitions），`RESULT=FAIL`；
- stock SystemUI：exit 0，1 source（1 definition）/ 36 target（0 definitions），`RESULT=PASS`。

Task 078 已否决一次性 `Scope.ALL` JarJar + 删除 hidden definitions 的所有权不安全算法，也否决 post-R8 DEX rewrite 和以 Soong-prebuilt SystemUI code 代替源码编译。pre-R8 变换仍是首选方案族，但具体的 AAR 变体清单、Android/JVM project output 范围以及 R8 对 hidden-name library classes 的真实解析仍缺实验证据，因此不得直接实现。

## 实验计划

### E1：463 个 stock R8 输入的完整变体与 ownership 清单

逐项解析 `withres/SystemUI.jar.rsp` 的全部 463 个 token，不抽样。每项记录输入路径、Soong owner/variant、是否走 `repackaged-jarjar`、725-rule source/target reference 与 definition 统计、Gradle counterpart 或明确的 no-counterpart 分类、以及是否进入 E2/E3。另对全部 17 个 Gradle 模块分类 Android source / JVM / res-only / source-empty app，并冻结当前 Release project outputs 的路径、SHA-256 与处理策略。

完成门：463/463 已分类、17/17 模块已分类、无 `UNKNOWN`；任何无法证明的映射使 E1 失败，不得靠猜测补齐。

### E2：受影响 AAR 的 repackaged 变体 scratch 干跑

只在 `/tmp/task079-c5-jarjar-e1-e4/` 中，根据 E1 清单从现有 AOSP `out/` 的 `repackaged-jarjar` 中间产物构造 scratch AAR。不得修改 `libs/` 或 AOSP `out/`。逐个核对：

- 当前 AAR 的非代码 ZIP entries 与 scratch AAR 字节一致；
- class entry name set 一致；
- critical 原名引用归零，所需 hidden 引用出现；
- 725-rule hidden target definitions 始终为零；
- 每个 E1 判定为受影响的 AAR 都有结果，不允许漏项。

### E3：project/JVM 编译产物 scratch JarJar 干跑

使用现有 Release 编译中间产物的只读副本，不启动 Gradle。区分 Android module 的本地 javac/Kotlin outputs 与 external dependencies；不得把 `Scope.ALL` 或合并依赖误当 PROJECT output。JVM modules 单独盘点。

每个拟变换 artifact 在执行前必须满足 725-rule source matching definitions = 0；若不满足，该 artifact 不执行 JarJar，E3 记 FAIL 并将候选算法升级给用户裁决。对满足前置条件的 artifact，以 AOSP host `jarjar.jar` + 冻结规则在 scratch 运行，记录耗时，并断言所有原名 rule references 均按映射消失/转为 target、target definitions = 0。无匹配引用的模块需记录为 no-op，不得悄悄遗漏。

### E4：standalone AGP bundled R8 正/负探针

直接调用：

```text
java -cp <builder-9.3.1.jar> com.android.tools.r8.R8 \
  --release --no-tree-shaking --no-minification --no-desugaring \
  --lib <android.jar> --output <scratch-output> <scratch-program.jar>
```

scratch program 只定义 probe class，以字段/签名引用四个 critical hidden targets，不定义任何 target。正向使用 SysUISdk `android.jar`，要求 exit 0、无 missing-class diagnostic、输出仍引用四个 hidden targets 且 target definitions = 0。负向使用官方 `android-37.0/android.jar`，要求非零退出并对四个 hidden targets 给出 missing-class diagnostics。不得添加 `--pg-conf`、`dontwarn` 或任何 suppress 配置。
